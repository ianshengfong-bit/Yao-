# Yao｜消防工程行政管理

> 專為消防工程行政工作設計的雲端管理系統。

Yao 是一套以消防工程日常行政管理為核心的 Web App，用來集中管理案場、工作、進料／出貨、人員安排、查驗、工作紀錄與提醒。

目前採用 Firebase 作為登入與雲端資料儲存服務，支援 Windows、macOS、iPhone 與 Android 等裝置透過瀏覽器使用。

---

# 🏗️ 案場管理

可以建立與管理不同案場。

案場資料包含：

- 案場編號
- 案場名稱
- 地址
- 聯絡人
- 聯絡電話
- 備註

每個案場可以查看與管理自己的工作。

### 工作狀態

工作依照狀態分為：

- 進行中
- 已結束

完成工作後會自動歸入「已結束」區域，避免大量已完成工作持續堆積在主要列表。

恢復工作後則會重新回到進行中。

---

# 📦 進料／出貨

# 🔔 提醒中心

Yao 目前具有工作提醒機制。

支援：

- 提前提醒
- 提前 1 小時提醒

已確認的提醒不會因為重新整理頁面而無限重複出現。

# 🔒 資料與帳號

Yao 使用 Firebase Authentication 進行使用者登入。

登入後的資料與使用者帳號關聯，不同帳號使用各自的資料空間。

密碼由 Firebase Authentication 管理，Yao 本身不在瀏覽器 LocalStorage 中儲存使用者密碼。

> 請勿將 Firebase 私密設定、帳號密碼或其他敏感資訊寫入公開 Repository。

# 🚧 開發方向

目前不急著大量增加功能，優先改善實際工作流程與操作體驗。

預計方向：

- 今日工作總覽
- 全域搜尋強化
- 工作優先級
- 案場進度
- 現場照片
- 更多行動裝置操作優化
- 更完整的資料統計
- 其他消防工程行政需求

以上項目會依實際使用需求逐步評估，不代表全部已經完成。

---

# 📌 開發原則

Yao 的設計方向：

> **簡單、快速、實用。**

增加新功能以前，優先確認是否真的能減少消防工程行政工作的時間。

避免為了增加功能而讓操作變得複雜。
